# Right-hand-man
Right hand man is a &-Key macropad with built in LED lights and an Oled display. Its purpose is to make normal shortcut keys related to media much more accesible.

# Features
- 128x32 OLED Display
- EC11 Rotary encode
- 6 SK6812 MINI-E LEDs
